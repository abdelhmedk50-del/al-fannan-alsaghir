# الفنان الصغير — Android

نسخة Android من تطبيق تعليم الخط العربي للكبار والصغار.

## ما تم تجهيزه
- اسم التطبيق: الفنان الصغير
- Package ID: `com.alfannan.alsaghir`
- Target SDK: 36 (Android 16)، وفق متطلبات Google Play الحالية للتطبيقات الجديدة.
- واجهة عربية RTL.
- محرر كتابة، ألوان، تشكيل، حفظ، نسخ.
- خطوط عربية مضمّنة محليًا: Amiri، Noto Naskh Arabic، Noto Kufi Arabic، Noto Nastaliq Urdu، بالإضافة إلى خط لاتيني.
- أيقونة التطبيق مبنية على شعار الفنان الصغير.

## إخراج APK وAAB
افتح المشروع في Android Studio ثم اختر:
- Build > Build APK(s) لإخراج APK تجريبي.
- Build > Generate Signed Bundle / APK ثم اختر Android App Bundle لإخراج AAB للنشر.

للنشر على Google Play يجب توقيع إصدار النشر، واستخدام AAB. لا ترفع مفتاح التوقيع داخل المستودع.

## ملاحظة عن الخطوط
الملفات المضمّنة هي خطوط متاحة محليًا في بيئة البناء. لإضافة رقعة/ديواني/ثلث حقيقيين يجب إدخال ملفات TTF/OTF مرخّصة لهذه الخطوط قبل الإصدار النهائي.
